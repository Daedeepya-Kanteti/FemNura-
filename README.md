## 💡 The Problem & Clinical Motivation

Women face systemic challenges in contemporary healthcare systems:
1. **Symptom Dismissal & Gaslighting:** Fatigue, chronic pain, and hormonal shifts are frequently dismissed as "just stress" or "normal pain," causing average diagnosis delays of 7–10 years for conditions like endometriosis and autoimmune disorders.
2. **The "10-Minute Appointment" Dilemma:** Patients walk into brief clinical consultations overwhelmed, forgetting symptom chronologies, triggers, or correlations with their cycle.
3. **Emergency Blind Spots:** During medical emergencies, first responders often lack quick access to blood types, known drug allergies, pre-existing conditions, or emergency next-of-kin contacts.
4. **Data Privacy Fears:** Commercial menstrual tracking applications frequently monetize or leak intimate reproductive telemetry.

**FemNura solves this through a private, compassionate, and clinically structured ecosystem designed to turn scattered daily health observations into actionable, dignified healthcare decisions.**

## ✨ Key Feature Modules

### 1. 🩺 AI Doctor Q-Gen (Appointment Preparation)
- Synthesizes user-logged symptoms, severity patterns, emotional fluctuations, and cycle phases into prioritized, clinically articulate questions.
- Generates a structured discussion sheet so women walk into doctor consultations empowered and prepared with concrete data points.
- Printable and downloadable discussion briefs for clinic visits.

### 2. 🩸 Menstrual & Ovulation Cycle Tracker
- Tracks cycle phase chronologies: Menstrual, Follicular, Ovulation, and Luteal.
- Flow intensity, symptom correlation, and fertile window awareness.
- Predictive insights tailored to hormonal wellness without intrusive notifications.

### 3. 🌡️ Smart Symptom & Fatigue Tracker
- Multi-dimensional symptom logging: severity (Mild, Moderate, Severe), duration, notes, and triggers.
- Visual trend analysis correlating physical discomfort with daily activities and sleep.

### 4. 🧘 Emotional Wellness & Mood Tracker
- Daily mood check-ins (Calm, Energetic, Overwhelmed, Anxious, Down).
- Captures mind-body interactions and hormonal mood swings across cycle phases.

### 5. 🚨 Emergency SOS Protocol & Hospital Locator
- **1-Tap Emergency Trigger:** High-contrast SOS button available globally across the app.
- **Live ER & Hospital Distance Calculations:** Integrates high-precision browser GPS with automatic network-based and regional preset fallbacks when device hardware permissions are restricted in sandboxes.
- **Instant Emergency Services Dialing:** Quick-dial buttons for local emergency response and primary trusted contacts.

### 6. 🪪 Care Circle & Digital Emergency Wallet Card
- Generates a scannable **Emergency QR Code** for quick triage.
- Publicly accessible Emergency Summary View displaying blood type, allergies, conditions, and emergency phone numbers.
- **Downloadable Emergency Card:** Exportable HTML/PDF-ready emergency medical summary to carry in a purse or phone wallet.

### 7. 📁 Medical History Vault
- Organize laboratory test results, ultrasound scans, doctor prescriptions, and vaccination records in one secure location.
- Category tagging and document previewing with client-side security.

### 8. ⏰ Adaptive Reminders ("Nudge & Nourish")
- Non-intrusive reminders for hydration, daily mood logging, medication regimens, and cycle check-ins.
- Customizable intervals and active toggles.

### 9. 📚 Women's Health Education Hub
- Evidence-based health literacy modules written in empathetic, accessible language.
- Topics covering iron-deficiency anemia, hormonal balance, reproductive rights, and cycle phases.

### 10. 🛡️ Data Sovereignty & Multi-Profile Architecture
- **Zero Third-Party Telemetry:** No user data is sold, tracked, or sent to advertising networks.
- **Multi-Account Switching:** Support for shared family devices with clean logout and isolated storage partitions.
- **Complete Data Export:** One-click full health record download.

## 🛠️ Technical Architecture & Stack

| Layer | Technologies |
| :--- | :--- |
| **Frontend Framework** | React 18 (Functional Components, Custom Hooks) |
| **Build Tool & Bundler** | Vite 5 (Fast ESM compilation & optimized production builds) |
| **Routing** | React Router DOM v6 (Nested routes, auth guards, query parameter sync) |
| **Styling & Design System** | Tailwind CSS (Tailored color palette: Deep Plum, Soft Lavender, Rose, Sage, Ivory) |
| **Animation & Transitions** | Framer Motion (Smooth layout transitions, modal reveals, accordion interactions) |
| **Icons & Visuals** | Lucide React |
| **QR Code Engine** | `qrcode` (SVG and Canvas QR matrix generation) |
| **Location & Geolocation** | HTML5 Geolocation API + Reverse Geocoding + Regional Fallback Engine |
| **State & Persistence** | React Context API + LocalStorage Partition Engine (`femnura_userdata_v2_*`) |

## 💻 Local Development Setup

To run FemNura locally on your computer:

```bash
# 1. Clone or download the repository
cd femnura

# 2. Install project dependencies
npm install

# 3. Start the Vite local development server
npm run dev

# 4. Open http://localhost:3000 in your browser
```

To build for production:

```bash
npm run build
```
